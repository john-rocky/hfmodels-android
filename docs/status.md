# Version history

**Status: 0.3.0, early.** Three devices verified: a Pixel 8a for chat (the table below), a Galaxy S26 for typed decisions and voice (the tables of those sections), and a Pixel 11 Pro for the catalog's `litert_lm` models on LiteRT-LM 0.19.1 (`docs/models.md`), all in `tested-runtime-matrix.json`; the API may still move before 1.0. 0.3.0 runs on LiteRT-LM 0.19.1. An app now needs Kotlin 2.3.0 or newer. The bundled catalog pins nine models at newer commits, and on this runtime the SDK refuses `litert-community/Qwen3-4B-Instruct-2507` with `RUNTIME_VERSION_MISMATCH` (`docs/models.md`). 0.2.0 added voice: a new module `hfmodels-voice` with which the phone hears a request, acts on it with its own tools and answers aloud, offline (the section "Voice", `samples/voice`), and tool calls on `Tasks.Chat`; and a second decision family, Julia-1 (`litert-community/Julia-1-LiteRT`, its own table in the section "Typed decisions"), three more (GLiNER2.5-Decide, GLiClass-Edge v3.0 and Open-Decision DeBERTa-v3-Large; the last table of that section) and `samples/promises`, a screen that sorts a conversation's sentences into promises, requests and plans. 0.1.2 added typed decisions (module `hfmodels-litert`: `EncoderDecisions` on the `laya` decision encoders, that section, and `samples/decide`). 0.1.1 added thinking models (their reasoning arrives in `Message.channels`, not in the text), `Message.text`, a resolver that never auto-selects a profile whose only device record is a FAIL, and a drop-in device check for any app (`samples/chat/src/androidTest/.../ChatDeviceCheck.kt`).
